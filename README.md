# Photo Portfolio

Photography portfolio with a horizontal scrolling gallery and hover slideshows.

Live: https://smallbath.github.io/photo-portfolio/

## Built with

HTML, CSS, vanilla JavaScript, GSAP.

## Running it

Open index.html in a browser. Or:

    python3 -m http.server 8000
